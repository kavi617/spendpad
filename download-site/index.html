GOOD TO KNOW

Questions, answered.

Does SpendPad need an internet connection?+

Expense tracking and local storage work offline. Internet access may be used by Android or the selected source when downloading an update.

Where is my expense data stored?+

SpendPad stores expenses on your device. You can export a JSON backup and manage that file yourself.

Why does Android show an installation warning?+

Android may show security prompts for apps installed outside an app store. Check that the APK came from the linked SpendPad GitHub Release before continuing.

Which Android versions are supported?+

The current APK reports minimum SDK API 24 (Android 7.0). Actual availability can depend on the device and Android version.
